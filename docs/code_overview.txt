# Project Structure Overview

This repository contains MATLAB code organized into modules for control, modeling, optimization, and experiment execution. Below is the description of the folder structure.

In the main folder you can find scripts for executing simulations, performing teaching by demonstration, and generating results.

1. mainTeachingByDemonstration.m 
------------------------------
This MATLAB script demonstrates a Teaching by Demonstration (TbD) approach for training 
a neural network controller on a robotic system (e.g., Pendubot or CartPole). 
The core idea is to first generate expert demonstrations using classical controllers 
(PID or LQR), and then use those demonstrations to train a neural network controller 
via optimization (Adam).

2. perturbedTrajectoriesTbD.m
------------------------------
Generates expert demonstrations by simulating trajectories from an initial state using 
a given teacher controller. Two types of trajectories are produced:
- The base trajectory from xInit using the teacher.
- Augmented trajectories by perturbing the base trajectory with Gaussian noise.

Outputs:
- all_traj_x, all_traj_tau: Concatenated state and torque data for all generated trajectories.
- all_x, all_tau: Cell arrays with individual trajectory data.

3. costAndDerBuilderTeaching.m
-------------------------------
Defines the cost function and its gradient for training a neural network controller. 
The cost is based on the Mean Squared Error (MSE) between the neural network's predicted 
torques and the teacher's torques over N time steps.

Features:
- Validates neural network input/output dimensions against the system model.
- Supports inequality constraints (though unused).
- Uses CasADi to generate symbolic expressions and gradients.

4. creatingGridBoundUncertainVariable.m
----------------------------------------
A helper function used to define bounds for uncertain parameters in the system.
It creates upper and lower bounds for each element in v_nominal based on the offsets 
provided in struct_env_var.

Usage:
- struct_env_var = creatingGridBoundUncertainVariable(v_nominal, struct_env_var);

5. integra.m
------------
Defines a class for performing one-step forward integration of system dynamics using
CasADi symbolic functions. Supports injecting Gaussian noise as perturbations for simulating
trajectory rollouts with uncertainty.

Features:
- Accepts symbolic system dynamics and builds a CasADi function for integration.
- Implements Euler integration: `x_next = x + (f(x, u) + R) * DT`
- Supports noise injection (`R`) and parameterized environment variables (`v`).
- Returns symbolic CasADi function `F(v, x0, r, u)` with outputs `xf` (next state) and `qf` (cost).

Usage:
- Used during data generation to simulate the evolution of states under noisy conditions.

6. globalNormalize.m
---------------------
Normalizes a state or control vector to the range [-1, 1] using element-wise min-max
scaling.

Inputs:
- Xk: Vector of state/control values to normalize
- vec_norm_in: Cell array of structs with `.min` and `.max` fields for each element

Features:
- Automatically handles divide-by-zero edge cases
- Useful for preprocessing inputs/outputs of neural networks during training and inference

Usage:
- Xk = globalNormalize(Xk, vec_norm_in);


7. main.m
---------

This MATLAB script runs the full training or testing loop for optimizing a neural network controller on a robotic system (e.g., Pendubot).
In training mode, it initializes the controller, sets up the symbolic model and cost function, and optimizes the controller parameters using one of several supported optimizers (e.g., Adam, Yama, IPOPT).
In testing mode, it loads a previously optimized controller and simulates its performance.
All results, parameters, and settings are saved in a structured folder for reproducibility and later analysis.


8. costAndDerBuilder.m
--------------------
This MATLAB class builds the cost function and its gradient for optimizing a neural controller.

It simulates the system over N steps, applying control inputs generated by the neural network and optionally denormalizes them. Noise is symbolically injected at each step. The total cost is accumulated from running and final cost terms.

The class produces two CasADi functions:
- Jfun: evaluates the total cost given parameters and noise
- gradJ_: evaluates the gradient of the cost

Used in reinforcement-style training of neural controllers.

9. flatnessBuilder.m
-----------------
This MATLAB class constructs a flatness-based regularization term for optimization of neural network controllers.
It computes the flatness score B and its gradient with respect to the controller parameters, which is used during training.

Two modes are supported:
- First-order flatness based on the gradient of the cost function.
- Second-order flatness using the Hessian (curvature) of the cost.

Optional support for integral flatness via Monte Carlo sampling around nominal environment parameters is included.

10. visualization.m and visualizationAux.m
-----------------

This code is used for observing the trajectories for different parameter values

## robotics_results/test_drive

Inside test_drive folder


1. experimentEnvOptConf.m
--------------------------
Defines experimental parameters for training and evaluation of control strategies.

Key Sections:
- Control Horizon:
  - N: Number of time steps (e.g., 150)
  - DT: Time step duration (e.g., 0.01s)

- Flatness Parameters:
  - epsilon_flat: Stability threshold
  - dumping: Damping parameter
  - type_of_flat: Structure defining flatness approach ('1orderStd' or '2order'), Monte Carlo sampling, etc.

- Optimization Configurations:
  Supports multiple optimization schemes:
  - 0: Teaching by Demonstration
  - 1: Performance Gradient
  - 2: Projected Gradient
  - 3: IPOPT
  - 4: Projected Gradient + AdaGrad
  - 5: Feppon-Projected

Each optimizer (adam_opt, yama_opt, etc.) defines:
  - Number of iterations
  - Step sizes
  - Desired cost values (J_val_des, B_val_des)
  - Noise parameters for state perturbation

Also stores the file path using:
  `out.absolute_path_to_save_exp_env_opt_conf = matlab.desktop.editor.getActiveFilename;`

2. neuralControllerConf.m
---------------------------
Configures and initializes a neural network controller.

Main Features:
- Specifies architecture using `layer_size` (e.g., [4, 10, 1] for Pendubot).
- Defines activation functions:
  - Hidden layers: `tanh`
  - Output layer: `identity`
- Normalization Flags:
  - out_normalization_flag: Enable output normalization
  - in_normalization_flag: Enable input normalization
- Uses CasADi symbolic framework.
- Returns:
  - control_method: Configured neural controller object
  - absolute_path_to_save: Path of the configuration file

The obtained results are saved in the folder results

## +optim/
Custom optimization algorithms used in the experiments.

- 'adamOptimizer.m' – only performance (i.e., task execution)
- 'fepOptimizer.m' – optimizing flatness with a performance constraint
- 'ipopOptimizer.m' – similar to Feppon by using classical optimization approach
- 'yamaAdaGradOptimizer.m' – both flatness and performance
- 'yamaOptimizer.m' – like Adam
